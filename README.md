# PC Parts Finder

複数の中古販売サイトから条件に合う中古パーツを集め、紛らわしい出品を除外して、安い順に比較できるWindowsアプリです。

## できること

- メモリモード: DDR4メモリを「容量・枚数」と「速度帯」で指定して検索
- キーワードモード: 型番や商品名（例: Surface Pro 8）で横断検索。価格帯と除外ワードで絞り込み
- メルカリ、Yahoo!フリマ、ラクマ、じゃんぱら、パソコン工房中古、ハードオフの販売中商品を横断取得（キーワードモードはメルカリ、Yahoo!フリマ、ラクマ、じゃんぱら）
- 容量・枚数違い、ノートPC用（SO-DIMM）、サーバー用、ジャンク、売り切れ・終了済みを除外（メモリモード）
- キーワードモードは内容を判定せず、販売中と価格帯・除外ワードだけで絞り込む
- 販売中を確認できた出品を、商品表示価格の安い順で画像付きで一覧表示
- 商品詳細は既定のブラウザで開いて確認

## ダウンロード

インストールは不要です。下のページから `PC-Parts-Finder.exe` をダウンロードして、ダブルクリックで起動します。

- https://github.com/otakichi1985/pc-parts-finder/releases/latest

起動中に新しいバージョンが公開されると、アプリ内で更新を案内し、ワンクリックで自動更新します（ダウンロードして自分を置き換えて再起動します）。

## 動作環境

- Windows 10 / 11
- WebView2 Runtime（Windows 10 / 11 には標準で含まれています）

## 使い方

1. アプリを起動する
2. 検索条件パネルで「メモリ」か「キーワード」を選ぶ
3. メモリ: 容量・枚数、速度帯、必要ならメーカー・型番を指定する。キーワード: 探したい語と、必要なら価格帯・除外ワードを指定する
4. 検索したいサイトを選ぶ
5. 「中古価格を横断検索」を押す
6. 価格の安い順に並んだ候補から「商品ページを開く」で詳細を確認する

## 注意事項

- コード署名（有料証明書）をしていないため、初回起動時にWindowsが「不明な発行元」と警告することがあります。**「詳細表示 → 実行」**を選んでください。
- 送料は未取得のため、現在は商品表示価格での暫定順です。
- オークション（入札）形式の出品は検索対象から除外しています。
- キーワードモードは内容を判定しません。キーワードに一致した販売中の出品をそのまま価格順に並べるので、詳細は必ず商品ページで確認してください。
