# PC Parts Finder

複数の中古販売サイトから条件に合う中古パーツを集め、紛らわしい出品を除外して、商品表示価格の安い順に比較できるWindowsアプリです。

## できること

- 6つの検索モード: メモリ、グラフィックボード、CPU、マザーボード、SSD、キーワード横断
- メモリ: DDR4/DDR5、容量・枚数（64GB以上の構成を含む）、速度帯、メーカー・型番で検索。容量・枚数のラベルに総容量を併記
- グラフィックボード: チップメーカー、ボードメーカー、型番で検索
- CPU: メーカー、シリーズ、型番で検索
- マザーボード: CPUソケット、チップセット・型番で検索
- SSD: 接続方式、容量、メーカー・型番で検索
- キーワード横断: 型番や商品名で横断検索。価格帯と除外ワードで絞り込み
- メルカリ、Yahoo!フリマ、ラクマ、じゃんぱら、パソコン工房中古、ハードオフの販売中商品を取得（メモリ）。GPU・CPU・マザーボード・SSD・キーワード横断はメルカリ、Yahoo!フリマ、ラクマ、じゃんぱら
- 型番の英数字一致で絞り込み（例: `12700` は `12700F`、`12700K`、`i7-12700` に一致し、価格の `12,700` には一致しない）
- PC本体、ノートPC、BTO、組み立て代行、マザーボードとのセット、箱・付属品のみ、モバイルCPU、ジャンク・動作不良を除外
- フリマで動作確認の記載がないパーツは「要確認」に分離。じゃんぱらなどの店舗出品は候補に残す
- 「要確認も表示」「除外も表示」で、判定理由を確認できる
- 販売中を確認できた出品を、商品表示価格の安い順で画像付き表示
- 商品詳細は既定のブラウザで開いて確認
- 起動中に新しいバージョンが公開されると、アプリ内で更新を案内し、ワンクリックで自動更新

## ダウンロード

インストールは不要です。下のページから `PC-Parts-Finder.exe` をダウンロードして、ダブルクリックで起動します。

- https://github.com/otakichi1985/pc-parts-finder/releases/latest

## 動作環境

- Windows 10 / 11
- WebView2 Runtime（Windows 10 / 11 には標準で含まれています）

## 使い方

1. アプリを起動する
2. 左のパーツ一覧から検索モードを選ぶ
3. 条件を指定する。メモリは容量・枚数と速度帯、GPUはメーカーと型番、CPUはメーカーとシリーズ、マザーボードはソケット、SSDは接続方式と容量、キーワード横断は検索語を指定する
4. 検索対象のサイトを選ぶ
5. 「検索」を押す
6. 価格順の候補を確認する。必要なら「要確認も表示」「除外も表示」で理由を見る
7. 「商品ページ」で状態・付属品・送料を確認する

## 注意事項

- コード署名（有料証明書）をしていないため、初回起動時にWindowsが「不明な発行元」と警告することがあります。**「詳細表示 → 実行」**を選んでください。
- 送料は未取得のため、現在は商品表示価格での暫定順です。
- 商品の動作状態は検索結果カードの文言で判定しています。商品詳細ページの説明までは取得しないため、購入前に必ず商品ページで状態を確認してください。
- フリマで動作確認の記載がないパーツは「要確認」に分けています。店舗出品は候補に残します。
- オークション（入札）形式の出品は検索対象から除外しています。
- キーワード横断は内容を判定しません。キーワードに一致した販売中の出品を価格順に並べるので、詳細は必ず商品ページで確認してください。
