# PC Parts Finder Capture

Chrome / Edgeで閲覧中のメルカリ商品をPC Parts Finderへ送る、将来用の補助機能。現在の主経路はデスクトップアプリ内WebView。

## 現在できること

- `status=on_sale` と画面上の「販売中のみ表示」の両方を確認する
- 商品ID、タイトル、価格を重複なく取得する
- 32GB×2のデスクトップDDR4候補、要確認、除外へ分類する
- SO-DIMM、16GB×2、PC本体、現在価格だけのオークションを推奨候補へ混ぜない
- 対応ページの取得結果をPC内だけのローカル接続へ返せる

## ビルド

`app` で `npm run build:extension` を実行する。Chrome / Edgeの「パッケージ化されていない拡張機能を読み込む」で指定するフォルダは `extension`。

## 現在の制限

- 通常検索では不要。閲覧中の商品を後から追加する用途は未実装
- 商品詳細ページを再確認する処理は未実装
- メルカリ以外は未対応
